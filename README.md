# Skärgårdsbyn: buggar och önskemål

Här rapporterar du som testar spelet Skärgårdsbyn fel du hittar och ändringar du önskar.

Spelet finns på <https://skargardsbyn.jonasolson.se/>.

## Så rapporterar du

1. Logga in på GitHub. Du behöver ett konto, men ingen inbjudan.
2. Titta gärna först bland [ärendena som redan finns](https://github.com/KaptenKatthatt/skargardsbyn-feedback/issues?q=is%3Aissue). Finns din sak redan kan du skriva en kommentar där.
3. Tryck på [Nytt ärende](https://github.com/KaptenKatthatt/skargardsbyn-feedback/issues/new/choose) och välj formulär:
   - **Buggrapport** när något inte fungerar som det ska.
   - **Ändringsönskan** när något fungerar, men borde vara annorlunda, eller när du saknar något.
4. Fyll i formuläret och skicka. En sak per ärende.

Spelversionen hittar du under Inställningar i spelet.

## Det här är offentligt

Alla kan läsa det som skrivs här. Skriv därför inte din testkod, din mejladress eller andra personuppgifter, och kontrollera att de inte syns i skärmbilder. Vill du säga något som inte ska vara offentligt använder du "Skriv till Jonas" i spelets inställningar.

## Vad händer sedan?

Varje ärende får en etikett som visar läget:

| Etikett | Betydelse |
| --- | --- |
| `ny` | Inte genomgången än. |
| `bugg` / `ändring` | Vilken sorts ärende det är. |
| `allvarlighet: kritisk`, `hög`, `medel`, `låg` | Hur allvarlig buggen bedöms vara. |
| `åtgärdad` | Rättad, och kommer med i nästa uppdatering av spelet. |
| `dubblett` | Finns redan rapporterad i ett annat ärende. |
| `åtgärdas inte` | Kommer inte att ändras. Skälet står i ärendet. |

Ärendet stängs när rättningen finns i testversionen av spelet. Önskemål om ändringar läses och vägs mot spelets plan, men alla kan inte bli av.
